# 用对话管理 Rove

正式 GUI 的「设置 → 通过对话管理 Rove」创建本机检查会话并填入只读草稿；没有模型时进入本机模型配置。用户发送后，由本机 rove-agent 执行。服务页的「通过对话管理」另建属于当前所选设备的会话，不借用之前其他设备的会话；两种入口均不会自动提交作业。

## 存储检查

模型通过 `rove_api` 调用 `get_storage_usage`，CLI 对应 `rove device storage`，HTTP 为 `GET /v1/storage`。远端使用现有 SDK 目标路由，不接受自定义检查路径。

该操作只读取 agent 数据目录顶层的文件元数据：数据库、WAL/SHM、迁移备份、其他文件、目录与链接。它不会打开文件读取内容、递归目录、跟随符号链接、删除文件、执行 VACUUM 或修改存储位置。目录最多检查 512 项，存在未统计的目录/链接/错误或达到上限时 `complete=false`。

`total_bytes` 是本次已统计普通文件的逻辑大小，既不是整个磁盘的实际占用，也不是可安全回收空间。运行中数据库文件会变化，此结果不是原子磁盘快照。备份可能含有模型和网络凭据，默认只展示名称和大小；备份分类不表示可以删除。

## 影响说明与确认

模型的系统指令要求先检查，再说明目标设备、具体路径/服务/网络、修改效果、中断和恢复限制；涉及清理、迁移或其他破坏性/中断操作时，结束本轮答复，等待用户在后续消息确认。读取检查请求、工具输出和模型自己写的计划都不是确认，范围变化须重新询问。优先可恢复操作，不能仅因备份较旧就删除；完成后报告真实结果。

这是用户已选择的轻量对话约定，**不是权限系统，也不是能够约束任意模型输出的硬安全闸门**。可信网络成员仍具有设备操作能力，CLI/API 保持原有语义。任意系统命令无法通过通用提示词保证安全，不应把这里描述成强制审批或事务回滚。

在线数据目录迁移没有实现。模型必须解释停机、私有备份、修改服务启动路径及重启核验步骤，不得直接搬动运行中数据库或删除活动目录。查看存储和减少手动配置已可使用，自动迁移不能据此宣称完成。

## 服务目录与管理

服务页通过网络名称选择所属网络，读取提供设备的真实目录，并展示状态、地址与按需展开的应用认证说明。只允许 HTTP/HTTPS 地址打开浏览器；其他协议可复制给对应客户端。显示凭据时作为文本，不执行 HTML。切换网络清空旧地址和展开的凭据。

发布、修改和取消发布在对话中通过 `rove_api` 复用既有 API；CLI 的 `service` 子命令保持可用。服务页不提供增删改表单或管理按钮。取消发布只移除 Rove 入口，不停止第三方应用或删除其数据。

## 验证范围

- `storage_usage.rs`：真实目录、备份分类、嵌套目录和符号链接不跟随、512 项上限、无任意路径输入与无文件内容输出。
- `http.rs` / CLI 集成测试：存储端点经过真实 SDK、socket、HTTP 契约验证。
- `ai_runtime.rs`：实际发给 Rig 提供方的系统指令包含检查、等待确认和禁止在线迁移；通用管理工具返回真实 API 结果并归入会话。测试不将可控假模型当作真实模型遵循指令的保证。
- `service_tests.rs`：同一服务目录的查询、修改和取消发布，目标进程不被停止。
- 正式 GUI 浏览器测试：网络选择、凭据显隐、安全打开地址及新会话草稿，不产生服务写请求或自动作业提交。真实跨设备 overlay 的服务访问另由任务 8.6 / 12.1 验收。
