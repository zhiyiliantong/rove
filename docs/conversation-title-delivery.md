# 图标导航、会话命名与归档操作

2026-09-20，正式 GUI 的五项反馈，纳入 `bootstrap-rove` 第 18 组；独立原型不变。

## 行为

- 移动底栏只显示三个图标，保留中文/英文无障碍名称和选中态；按最新澄清保持横向铺满屏幕，只降低高度至约 53px，点击区域至少 44px。对话详情继续隐藏底栏，桌面侧栏文字保留。
- 标题在原位置变为输入框，不弹窗；回车/失焦保存，Esc 取消，输入法确认不误保存。空白不提交，保存失败保留编辑内容。切换会话时迟到响应仅更新原会话。
- 新会话首条已接受消息生成简短标题：合并空白、最多 32 个 Unicode 字符，超长加省略号。不另行调用模型，也不改变后续聊天内容。手动改名永久优先；即使手动名称也是“新会话”，也不会被覆盖。
- `SessionCreate.auto_title` 和 `Session.title_source` 经 OpenAPI 定义；来源为 default/message/manual，显式 `SessionPatch.title` 标记 manual。CLI 默认无标题创建会自动命名，`--title` 默认固定，也支持 `--auto-title`；重启和重试保留状态。远端关联仅在确认作业接受时命名，未确认请求保持原名，查询恢复不会覆盖手动名称。
- 旧会话没有可靠来源标记，保留原名，不凭默认名称字样猜测用户意图、不批量改历史。不改变数据库结构或创建幂等输入。
- 右上角“+”移除归档当前会话及恢复/删除当前会话项，保留“归档管理”。普通列表仍有归档按钮；归档列表每行直接提供恢复和删除。删除弹窗绑定点击行，不会误用当前选中会话；先检查该行的活动作业/未确认请求，再由后端事务再次校验。检查失败/离线禁止确认，取消不删除。
