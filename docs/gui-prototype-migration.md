# 已确认原型 → 正式 GUI：迁移记录

2026-09-16 用户授权返回 bootstrap-rove，原型 0.6 及会话归档管理提案已归档。此记录对应第 13 组新增任务，不重写原 71 项平台验收记录。

## 本阶段实现

- `apps/rove-gui` 使用 Vue + PrimeVue 4.5.5 / Aura 1.2.5，桌面侧栏、窄屏底部三栏（会话/服务/网络），设置、模型、设备为次级页面。原生本机 Android/iOS 身份保持横屏底栏，不由所选远端设备决定布局。系统窗口装饰保留，由 Tauri 宿主提供最小化/最大化/关闭。
- 切页与切换设备选择保留会话组件、会话选择、草稿和作业订阅；每个会话保存独立草稿。新会话才使用新选择的执行目标，已提交远端请求与关联由 agent 持久保存。离开网络页关闭扫码相机。尚未提交的草稿仍不跨窗口或重启持久化。
- 用户/agent 气泡显示原有 SDK 快照和事件批次，不采用原型计时器生成回复；保留序号恢复、取消、分页、工具历史与真实错误。当前 output_tail 混合助手与工具文本，页面明确说明，并保留截断提示，不将其假称为纯助手最终回答。
- 安全 Markdown、代码、LaTeX 与说明段落复制，剪贴板不可用时手动复制；主动本地朗读和无本地语音降级，禁止自动加载外部图片/HTML。字体与资源随包分发，富文本组件懒加载。
- 服务页只保留查询、访问、复制和认证说明，不提供发布/修改/取消发布表单。`rove_api` 通用工具复用真实 OpenAPI 路由，支持设备、设置、网络/成员、服务查询和设置/服务修改。操作集合不包含任意 URL、远端 target、模型凭据或作业提交。
- 音乐/影院/代码代理/服务建议只填草稿，不自动提交命令。“管理 Rove”切回本机，独立创建会话并填写只读检查草稿；无模型时进入配置页，不创建空会话。系统提示要求变更前说明影响并取得用户确认；这不是强制授权闸门，自动存储迁移流程尚未实现。

## 真实通信与未迁移边界

生产路径仍为 Vue → Tauri `agent_call`/`agent_events` → rove-sdk → 本机 socket 或 overlay 远端。浏览器测试仅在测试进程注入 `__TAURI_INTERNALS__` fixture；正式包没有 mock 后备、演示种子或浏览器直连第三方模型。

归档迁移新增 3 个 agent 操作，当前 agent 36 操作、配置服务 3 操作由 bootstrap OpenAPI 定义。会话支持归档/恢复/删除，`list_sessions` 可用 `archived` 过滤，省略时保留旧客户端查询全部的语义。归档保留历史与已接受作业，禁止新提交和改名；删除只允许已归档且没有 queued/running/cancelling 作业的会话。数据库 v3 迁移前备份并补齐旧会话字段；删除只清理关联历史，不卸载应用或删除设备文件，保留 request_id 墓碑防止重试重新执行。CLI 删除要求 `--yes`，GUI 需确认对话框。

2026-09-17 增量：模型配置已迁移为真实共享连接/多型号目录，原生 Rig 提供商、获取型号、可编辑自动名称、默认和持久会话选择、首次配置网络引导已接入；新增 7 个 API，当前 agent 共 43 操作、SQLite v4。见 [核心模型链路](core-model-workflow.md)。账号会员登录不提供模拟成功。
