# 紧凑会话与网络内 API 同步

2026-09-20，正式 GUI 的六项反馈，属于 `bootstrap-rove` 第 17 组；不修改独立浏览器原型。

## 实现

1. 应答去掉“执行详情”和成功后的“已完成”。运行中取消、失败、离线及输出截断提示保留；后台记录、作业查询和 CLI 不删除。
2. 会话列表按创建时间倒序，新会话置顶；同时间以 session_id 稳定排序。正常聊天阅读顺序不变。OpenAPI `list_sessions` 新增 `order=asc|desc`，省略仍为兼容升序；GUI 和 CLI 默认请求倒序。分页游标绑定排序和归档筛选。
3. 手机进入会话隐藏主导航，返回列表恢复，桌面侧栏保留。输入框与消息区使用释放的高度，保留底部安全区域。
4. 顶栏压缩至约 53px，图标按钮触控区域至少 44×44px。
5. 引导页“添加模型”直接进入单个添加表单，已有型号也不先显示列表；取消回引导。仍须测试成功才能保存并推进，不自动推理、不修改已有连接。
6. API 同步由模型页移至本机网络列表中的运行中网络。选定网络后仅发现该网络设备，弹窗不能换网络；拒绝跨网络发现结果。用户仍须选来源连接、目标设备并明确确认覆盖，浏览器不接触已保存密钥；不传账号令牌、不自动广播同步。
