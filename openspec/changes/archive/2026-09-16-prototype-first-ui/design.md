## Context

动机参见 [proposal.md](proposal.md)。现有 `apps/rove-gui/src/api.ts` 直接调用 Tauri invoke，普通浏览器不能替代原生桥接。`bootstrap-rove` 的后台与平台验收继续独立保留；本变更不修改其进度。

2026-09-14 用户确认信息架构及以下补充设计，授权独立浏览器原型实施。2026-09-16 用户明确回复“验收通过”，确认当前原型 0.5（含对话管理 Rove 入口）并进入归档。此确认仅为原型验收，不代替真实 GUI/SDK 迁移授权。

## Goals / Non-Goals

**Goals:** 使用可复用的 Vue 页面与组件在浏览器验证完整交互；以连续响应式布局保持不同屏幕的功能可达性；明确区分模拟交互与真实设备操作。

**Non-Goals:** 本轮不连接真实 agent、不重写协议、不迁移现有 GUI、不部署设备软件、不新增登录/权限系统；不宣称浏览器模拟相机、native VPN 或后台任务等于实机支持。

## Decisions

### 1. 独立原型与后续接入分阶段

以 `apps/rove-prototype` 作为独立 Vue + TypeScript + Vite 工程，PrimeVue 为唯一主组件库。已有 GUI 保持不动。组件、页面和数据适配器分离，后续复用页面接入真实 SDK。

流程：功能组织确认 → 原型实现与浏览器部署 → 交互/多屏评审 → 明确确认记录 → 后续授权迁移。

### 2. 页面只依赖数据适配接口

```text
原型：Vue 页面 → 数据适配接口 → 可重置的模拟场景
后续：相同页面 → 同语义适配器 → Tauri → rove-sdk → rove-agent
```

模拟数据沿用已有状态词汇，新增模型关系和会话/任务关系单独定义为版本化原型 OpenAPI，不宣称已有后台支持。原型入口只组装模拟适配器，不提供真实端点切换；接口地址只是表单数据，不发起请求。只接受固定演示凭据，浏览器存储不保存用户输入的密钥。模拟分享使用独立标识，不能导入真实 Rove。

### 3. 响应式布局与主题

采用一个页面体系，不为手机/桌面维护两套业务逻辑。桌面/浏览器按宽度显示侧栏或底栏；移动平台固定底部导航，横屏/平板也不切到侧栏；平板按内容空间呈现单栏或主从分栏。断点依据内容而非设备型号确定，候选验证宽度为 320、360、390、768、1024、1440 CSS px，并在相邻宽度间连续缩放。

主题统一管理语义颜色、字体层级、间距、圆角、焦点与明暗模式。组件按需引入，具体 preset、主色和精确断点在样式评审时选定并记录。卡片、表单、弹窗、抽屉、导航在窄屏保持触达；长设备名、UUID、URL 和代码输出不得撑宽整个页面。备选是整体缩放桌面界面，但触控与可读性不满足需要。

### 4. 已确认的信息架构与三条体验路径

一级导航固定为会话、服务、网络；手机底栏、桌面侧栏。全局加号包含添加会话、添加网络、添加模型、加入网络、设置。模型列表入口放设置内。首页为会话，空状态引导添加模型。平台外观与宽度独立，浏览器默认不冒充原生窗口；桌面窗口按钮仅在明确的外观演示模式出现。

- 首用：首次保存模型 → 本机自动建立一次“初始化网络”会话 → 创建网络或加入网络 → 成功后显示名片 → 继续会话。不在每次添加模型时重复引导。
- 日常服务：服务导航 → 查看来源设备、地址、可达状态 → 打开服务；原型只打开模拟服务预览。不提供服务增删改、部署、启停按钮；需求通过会话提出，完成后刷新列表。
- 继续对话：发起设备本地会话 → 本机 rove-agent 委托目标设备 → 目标接收并保存任务 → 发起界面退出 → 重开原会话补取进度。未接收不显示成功，目标不可达显示最后已知进度，等待回答与失败分开。原型使用时间戳及本地存储重建演示进度，不是真实后台运行。

网络列表可保存多个网络，本机可同时连接多个不重叠的网络（2026-09-14 用户更新，替换此前单连接规则）；浏览不改变连接，连接/断开按网络独立操作。节点属于网络；节点详情显示信息及一次性同步选定模型配置，不引入远程会话替代本机会话。

模型以连接配置（名称、服务商、接口地址、凭据引用）加型号记录（一型号一条、引用连接）组织。一次演示认证后多选批量添加，可手填型号，接口地址默认填充且可改。同凭据只保存一次；默认模型单选。账号登录仅模拟支持的适配器流程，不等价于 Rig 通用 API 凭据。

创建网络自动填名称、随机十六进制密钥、初始节点，虚拟网段默认 DHCP，可切换手动。名片只含这四项；不含设备 ID、固定 IP、模型或账号凭据。加入支持模拟扫码、URL、JSON 文件、手动表单，不请求真实公共节点目录。

| 页面 | 主要动作 | 返回与状态 |
| --- | --- | --- |
| 会话列表/详情 | 新建、发送、附件、语音示例、选择模型、取消任务 | 返回列表；空、运行、排队、失败、等待连接、unsupported、重开恢复 |
| 模型列表/添加 | 批量添加、编辑连接、删除型号、默认单选 | 返回模型列表；验证失败、手动型号、无模型 |
| 网络列表/详情 | 创建、加入、连接/断开、编辑、删除、名片、查看节点 | 返回网络列表；未连接、等待 DHCP、已连接、网段冲突 |
| 节点详情 | 信息、模型一次性同步 | 返回网络；离线、不支持、同步成功 |
| 服务列表 | 浏览、过滤、模拟访问 | 不显示管理控件；空、可达、不可达 |
| 设置 | 模型入口、明暗主题、本机并发、演示场景及平台外观 | 返回；重置需确认 |

桌面会话主从分栏，手机列表与详情分屏；表单为响应式弹窗，详情返回保持草稿。节点与服务在手机用分行卡片，不强制横向表格。状态同时有文字与颜色。采用 Aura 主题、绿色主色与中性色表面作为首版视觉建议，非已验收结果。

### 5. 可审阅部署与验收

会话建议新增第五项“管理 Rove”，设置页顶部新增“设置不必自己找，告诉 Rove 你想怎么调整。”及“通过对话管理”按钮。两处共用入口，新建本机会话、目标固定此设备，只填入空间/运行情况检查草稿，不自动发送、不覆盖已有草稿。管理建议与其他建议的区别是始终另开本机会话，避免继承远端执行上下文。无模型时不创建会话，打开添加模型并解释原因；不改变首模型初始化网络流程。设置页保留手动配置，说明当前只演示、真实接入后的破坏性操作需说明影响并确认。不新增设备详情入口、存储管理页面、真实清理或迁移能力；复用现有 createSession/saveDraft/setSessionTarget 语义，无新增 OpenAPI。

欢迎页主标题下的产品标语更新为“数据自己掌握，跳出平台控制”，以主题强调色展示，窄屏按分句换行；保留功能介绍和原型标识。表达数据私有、自主保存及决定分享用途、不依赖平台出售数据或将数据访问商品化的产品方向，不泛指所有平台的实际行为，也不承诺使用外部模型或第三方软件时绝不发送数据。此轮不改变 API/存储行为。

音乐、私人影院和多台代码代理统一视为第三方软件部署场景。Rove 负责设备对等联通、设备管理、部署操作及服务登记/代理访问；每台设备上的 rove-agent（基于 Rig，沿用已确认名称）安装、配置及维护第三方开源软件。播放、媒体库、代码执行和代码代理间的专业协作由第三方软件承担。此前讨论中“Rove 自建多代码代理任务拆分/汇总编排”的建议不纳入本需求；不因此否定已有通用跨设备执行、进度恢复或并发能力。原型只调整说明与草稿，不新增专用管理页面或多代理业务引擎。

会话建议追加“建立自己的私人影院”“管理多台代码代理”，与音乐/查看服务建议共用组件；欢迎页及尚未发送用户消息的普通会话展示，初始化网络会话不展示。点击创建或使用当前会话并填入草稿，已有草稿追加保留，不自动发送；发送后隐藏建议。不改变原型 OpenAPI 或承诺真实部署能力。

部署静态构建产物，站点持续显示原型/模拟数据标识。部署前明确主机、监听范围和地址，不默认修改既有服务、防火墙或公网域名。路由刷新/深链接可用，或采用适合静态托管的路由策略。评审提供桌面/窄屏入口、场景切换和重置说明。

验收覆盖布局、键盘/触控、当前目标、输入保留、返回路径、主题和所有关键状态；模拟失败与成功不能只靠按钮变色。摄像头/剪贴板等环境能力不可用时明确提示，不伪造真实成功。无需接通系统能力即可完成原型交互评审。

## Risks / Trade-offs

### 2026-09-16 应答视觉细化（参考用户截图）

保留用户右侧气泡与助手左侧消息的会话结构；助手外层改为透明、无边框的正文，不再把所有内容包进有色卡片。此项替代下文助手气泡的外框样式，不改变任务关联、状态、详情和取消语义。

正文用 1rem 字体和 1.85 行高，独立公式/代码使用中性浅色圆角块，复制图标固定右上角、与滚动内容分区；长行在块内滚动，不撑宽页面。深色主题使用相同语义配色。说明复制不另占一行：桌面悬停/键盘聚焦显示，触屏常显；行内公式仍可复制源文。

回复底部仅保留已有复制、朗读/停止的低强调图标，提供可访问名称、悬停标题、停止状态和键盘操作。暂不增加截图中的点赞、点踩、分享或更多菜单。流式、Markdown/LaTeX、浏览器本地语音及手动复制降级保留；纯显示变化不新增或更改 OpenAPI 数据契约。

### 2026-09-16 按 Rig 筛选（原型 0.5，替代 0.4 的新增目录）

本轮追加反馈：自动生成的模型显示名称可逐条手动修改、恢复自动名，保存前 trim 并校验非空和本地唯一，不改型号 ID；按 exact model ID 的可选 model_names 映射传给原型 ModelImport，未指定项保持自动生成。校验失败不得新增部分连接或型号。

后续追加：型号预置在打开表单及切换供应商/认证等失效重置时默认全部选中，允许手动取消；不保留前供应商的 ID。对应自动名称立即显示，不要求先验证。旧“清除选择”指旧选择不沿用，现在以新目录默认全选替代空选择。

助手回复支持累积模拟流式：Run.output_text 为计时生成的 Markdown 前缀，150ms UI 轮询更新；不是模型 API/SSE。断连暂停，取消保留已输出内容，刷新按模拟任务时间恢复。完成后同一气泡显示关联最终消息，只有此时发布演示服务。输入“演示富文本和公式”可展示专用固定内容。

富文本使用锁定 markdown-it 15.0.2（html=false）与 KaTeX 0.18.7（trust=false、展开/尺寸限制）；本地打包资源，无 CDN，外部图片不自动加载，危险链接不能执行。代码、公式复制原代码/LaTeX，说明段落和整条回复复制原 Markdown；安全转换的 HTML 才进入 v-html。未闭合公式/代码流片段允许暂时按普通文本显示，不造成页面异常。

朗读/停止仅显式点击触发，使用浏览器本地 voice，流式过程中禁用朗读；无本地语音、API 不可用或错误均提示，不发云 TTS 请求。单条超过 4000 字符提示复制分段使用系统朗读。复制先使用 Clipboard API，局域网非安全上下文或权限失败时显示可选择的只读文本框，不宣称已复制。复制和朗读是浏览器本地交互，不新增后端 HTTP 操作。

会话改为用户右侧、助手左侧的气泡布局。去掉独立执行卡和进度条，执行状态、结果、取消及折叠详情包含在助手气泡中。新增消息可选 run_id 关联用户请求与最终助手结果，按原请求位置展示一个任务气泡，完成后原位更新，不把结果重复渲染为两条回复。旧无关联消息原样保留，无法定位的旧任务放在历史末尾，不猜测历史关联。Snapshot 仍 v3；仅增加可选字段，不重新提交任务。

- 用户要求以 Rig 支持的提供商为准，从既有 16 项筛选，而非继续扩充 Rig 的全部供应商。依据项目 Cargo.lock 固定 rig-core 0.42.0 的专用模块保留 12 项：OpenAI、DeepSeek、Anthropic、Google Gemini、Moonshot、Z.ai、MiniMax、Mistral、xAI、OpenRouter、Groq、Ollama。
- 新增目录移除 Qwen/百炼、火山方舟、硅基流动和自定义入口，不以“可能 OpenAI 兼容”作为入选依据。过滤的是供应商，不禁止通过保留的平台使用其他厂商的模型（如 Ollama 的 Qwen 型号）。预置型号不是白名单。
- Provider 增加 rig_provider，显式记录 google → gemini，其余保留项对应同名模块。智谱国内 zhipu 不冒充国际 Z.ai；新建使用 zai 与 Rig 默认国际站地址，旧 zhipu 不转换。Gemini / Ollama 新建地址对齐 Rig 原生根地址，历史地址不改。
- 旧条目保留内部元数据，仅编辑现有连接时显示“旧配置”与说明，不回流新增列表。旧 provider ID、名称、型号、凭据引用、默认模型、会话和地址完整保留；Snapshot 仍为 v3，兼容历史内部测试数据输入。
- OpenAPI 0.5 的 GET /providers 只返回 12 项和非空 rig_provider；历史 Connection.provider 保持开放字符串。新增目录不表示 Rove 后台已接入或所有型号能力通过验证，界面明确说明。既有后台仍仅 openai/openai_compatible，不在本变更中修改。

### 2026-09-14 评审更新（原型 0.2）

- 多网络取代单连接限制。按 IPv4 CIDR 起止地址检查相交/包含，不比较文本或前三段。`192.168.100/16` 规范化为 `192.168.0.0/16`，与 `192.168.100.0/24` 冲突。允许保存冲突配置，但不能同时连接。修改已连接/等待 DHCP 的配置前需断开此网络，不影响其他网络。
- DHCP 获取虚拟 IP 后才知道实际网段；待分配不是已连接。原型延时返回固定演示网段，第二个相同 DHCP 网段会冲突，离线场景持续等待且可取消。正式接入需对实际地址变化再次校验，由 agent 串行处理连接状态变化，冲突只停止新增/发生冲突的实例。
- NetworkCard 仍仅四项。`subnet` 为 CIDR 或 `dhcp`，不分享本机实际 IP/运行时状态。Snapshot 升级到 v2，网络各自携带 connection_status/resolved_subnet/local_ip；从旧浏览器快照迁移，保留会话/草稿。设备稳定 ID 不随网络改变；本机在各网络有不同地址。原型远端仍为网络内设备视图，正式 DTO 必须分离设备与多网络成员关系。
- 网络密钥使用 Web Crypto 生成 32 字节并编码为 64 位小写十六进制，默认密码框，显隐与重生成独立操作。EasyTier 的 network_secret 是共享字符串而非非对称私钥；手动导入保留非十六进制字符串，不把 Rove 默认格式说成 EasyTier 限制。
- 初始节点用可添加/移除的独立行，每行测试有等待、模拟可达、超时、格式错误。编辑/删除行使旧结果失效；连通不代表认证。浏览器不探测实际地址，正式探测需经 SDK → 本机 agent，按协议握手并设置超时。
- 会话加号的“模型”打开实际选择控件；移除执行设备下拉，仍展示推断目标与实际任务执行端。桌面附件只显示文件，移动端显示拍照/照片与扫一扫入口。扫码在原型只提供入网入口说明。
- 厂商列表 OpenAI / DeepSeek / Anthropic / 自定义，分别填官方 API 默认地址且可改。API 密钥与账号登录互斥；仅有相应官方工具适配器的厂商展示可用账号登录演示。账号凭据不发给表单中的 API 地址。切换厂商、认证方式、地址或密钥使旧验证/型号选择失效。
- 此更新只改原型与原型契约；既有 Rust 后台单网络行为和真实平台验收不因此变更。源依据及待接入风险见 `docs/prototype-handoff.md`。

- [模拟交互误被当作后台完成] → 永久演示标识，分离原型与真实验收记录。
- [未定导航过早固化] → 首项先评审功能组织，不以待办列表或文件状态暗示批准。
- [独立原型成为废弃代码] → 页面/组件与适配层分离，交接时以组件复用为目标；实际提取方式在迁移变更中验证。
- [屏幕变窄丢失能力] → 连续缩放、长文本、触控、缩放字体与横竖屏验收，不只检查少数截图。
- [原型引入需求与协议不一致] → 记录差异并先讨论，不修改 agent 契约来迁就界面。

## Migration Plan

本变更只交付独立原型及审核/交接记录。停止预览站点即可撤回原型部署，不影响现有 GUI 和用户数据。后续迁移须另行授权，复用确认的页面/主题，经 Tauri SDK 接入，再分别进行 GUI/CLI 对等及原生平台验收；不自动关闭 `bootstrap-rove` 的剩余任务。
