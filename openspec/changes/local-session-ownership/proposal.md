## Why

用户确认会话属于创建它的设备。GUI 将所选设备绑定为新会话执行目标，导致 Android 选择本机时创建失败，也错误地把整段会话交给另一台设备。

## What Changes

- 新建会话始终调用本机 agent，不携带 execution_target。
- 远程操作通过本机会话中的 agent 协议工具调用对方 agent，不改变会话归属。
- 保留旧关联会话和历史的兼容读取、执行语义，不静默迁移。
- 创建失败在桌面和手机列表页可见且可复制，不被后台刷新清除。
- 按用户后续确认增加本地设备别名：仅当前设备保存、全机名称唯一、网络中不同设备可用不同名称；会话先解析稳定目标再交由对端执行。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `ai-sessions`: 新建会话与设备选择解耦；明确旧关联兼容边界和会话内远程调用。

## Impact

共享 GUI、会话规格、AGENTS.md、浏览器回归测试；复用现有 agent 协议工具，不引入平台专属业务分支，不修改历史数据库。
