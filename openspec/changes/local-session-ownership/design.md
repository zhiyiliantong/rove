## Context

参见 proposal.md。ChatPanel 已把列表请求发给本机，但创建 body 从全局 target 派生 execution_target。创建失败共用轮询错误，移动列表隐藏详情。rove_api 目前禁止远端目标和会话操作。

## Goals / Non-Goals

Goals: 新会话本机编排；会话内明确远端协议调用；共享实现；创建错误可见。
Non-Goals: 不删除旧执行关联、不迁移数据库、不替用户执行部署任务、不将浏览器验证宣称为原生设备验收。

## Decisions

- 远端操作入口仅保留在会话；去除设备行“管理此设备”和设置页全局执行目标。同步模型的显式接收方选择保留，不改变全局浏览目标；历史关联会话的模型配置目标仅限该配置页，不扩散到网络/服务。
- 网络编辑沿用原型创建表单，允许显示名称、初始节点、地址模式、网段、本机 IP；key 只读且后端拒绝改写。EasyTier 身份名称沿用原值，修改显示名称不创建新网络。运行中保存自动执行停止→等待停止完成→保存→启动→等待运行完成，提前提示连接短暂中断；原本停止的网络不启动，失败准确显示所处阶段，不将 202 接收当作完成。

- 设备别名直接点击名称原位编辑，不展开新表单/弹窗；回车或失焦保存，Esc 取消，输入法选词不触发回车保存。清空可删除本地别名；保存失败保留输入，不修改原映射。

- 本地设备别名保存在当前 agent 私有数据库 metadata 中，键为 network_id/device_id；整个本机名称去首尾空白、忽略大小写后唯一。更新在数据库锁内原子检查，不修改对端 display_name，不出现在 hello 或网络分享中。别名 API 仅本机可用。解析读取当前网络成员事实，离线明确报错，不保存固定 IP 或按 IP 猜测身份。GUI 和会话工具共用此 API，重名不覆盖原映射。

- 新建请求从类型和组装入口移除 target；保留旧会话 execution_target 读取，避免中断既有任务。不是仅将本机 ID 特判。
- 扩展现有 rove_api 白名单和 SocketTarget，复用 agent 的 overlay 路由；远端会话/作业操作要求显式非本机目标，禁止递归创建 execution_target。不引入 shell SSH 或任意 HTTP URL 工具。
- 复用 create_session/submit_run 幂等 ID、查询和错误协议，提示模型检查远端实际状态和配置。system_exec 始终仅操作本机。
- 独立创建错误置于 chat-layout 两栏之外，占整行并复用 MessageCopy，后台轮询不修改。

## Risks / Trade-offs

- 网络名片每次打开均重新获取已保存的加入配置；保存尝试、离开视图与卸载组件时清除旧名片并递增生成序号。异步配置/二维码只允许写入当前序号，二维码与复制使用同一个 Base64 快照；加载中不误报读取失败。

- 远端需要模型配置 → 由其自身 agent 报告模型错误，不借用本机凭据。
- 历史关联仍存在 → 保留兼容路径，回归测试明确新旧差异。
- 网络丢响应 → 工具不自动重试写入，提示保留原 ID、先查询；持久工具调用记录保留输入和结果。

## Migration Plan

更新共享 GUI 和 agent 后重新打包才影响已安装版。无需数据库迁移，可回滚代码而不改历史。实际设备验收与源码测试分别报告。

## Installed follow-up: command output encoding

Windows 中文命令的 OEM/本地代码页字节不能无条件用 UTF-8 有损解码。共享 pipe 读取器保持 stdout/stderr、事件持久化和有界输出的同一条路径；Windows 薄适配读取当前 console 输出代码页，无 console 时使用系统 OEM 代码页，通过 Win32 转换成 Unicode，不修改全局代码页。逐行优先接受有效 UTF-8，否则使用本地代码页；长行保持有界，并避免截断 UTF-8/DBCS 字符。UTF-8 与本地编码本身可能有歧义，这不是任意二进制或任意程序自选编码的通用识别器。已被替换字符损坏的历史不自动重写。

## Installed follow-up: bounded network evidence

重连失败需要区分真实 EasyTier 成员/路由与本机接口就绪。`ROVE_NETWORK_TRACE=1` 仅用于显式启动的诊断进程：在私有 agent 目录独占创建随机命名 JSONL，2 秒采样一次，总量上限 4 MiB。白名单只包含节点编号、IPv4 数值、下一跳、连接端点（不含用户信息、路径、查询）、计数和时间；不输出配置、凭据或原始上游事件。默认关闭，不改变网络策略或共享 API，不因诊断写入失败改变业务结果。

## Runtime observation recovery (2026-10-08)

用户暂停之前的跨设备/Mihomo 排查，只修复运行时检查异常被当作永久停止。共享生命周期将实例列表/状态读取标记为观察操作：暂时失败或调和超时关闭当前业务入口、清空有效地址，但不停止底层实例、不改 enabled；以 starting 和可复制错误报告恢复中，按 1/2/4/8/16/30 秒退避重查。只有通过原有全部原生接口、路由、隔离检查才重新开放入口并清错；失败不重放会话/作业。显式停止立即取消退避且不自动重启。原生权限、接口、路由、隔离失败与已确认实例错误仍走原有安全失败处理；不自动触发系统授权。既有 enabled=false 的失败记录不迁移、不擅自启动。
