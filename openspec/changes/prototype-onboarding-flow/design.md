## Context

动机见 proposal。原型有独立 Vue 外壳、模拟模型/网络对话框和 Snapshot v4；首次添加模型会建立初始化网络会话。本变更跨页面控制与偏好生命周期，因此记录设计。

## Goals / Non-Goals

Goals：四页流程与可复看的教学动画，宽窄屏交互一致，旧数据无损。Non-Goals：正式 GUI、真实组网、真实模型调用、APK 或用户验收结论。

## Decisions

- 使用独立引导组件覆盖主页面区域，复用全局模拟对话框。引导期间保存模型或网络不跳出流程；旧的初始化会话仍只创建一次。相比复制表单，复用能保持验证规则一致。
- 引导偏好独立存储，包含完成标记、页码、下次启动重置标记。重置只置标记，本次内存页面保持；在新文档启动时消费。浏览器刷新/重新打开视作原型重启，路由切换不算。
- 新浏览器以空场景启动，已有 Snapshot 直接保留。测试显式装入日常种子，不依赖用户首次启动的默认场景。
- 教学画面用应用原生图标/CSS 动效，支持暂停和减少动态效果；输出 GIF 供审核下载，不将图片当作真实扫码配置。文案与操作留在 HTML 中，避免动画承载唯一操作入口。
- 第四页选建议仅新建并填入草稿，不提交作业；未配置模型时先打开模型配置并保留意图。完成/跳过后进入会话列表；移动只显示列表或详情，宽屏保留列表/详情双栏。新建和归档入口统一到加号菜单。
- 不新增 API：引导是浏览器展示偏好；业务操作继续使用 prototype.openapi.json 中现有契约。
- 审核反馈补充：`#/review-reset` 仅打开清空确认，不在访问/刷新时自动删除。复用模拟 `reset(empty)`，先校验本地存储写入；清空模型、网络、设备、服务、会话、任务及引导进度，保留主题和其他存储。要求先关闭同一原型的其他旧标签页，避免未刷新旧代码回写旧快照。

## Risks / Trade-offs

- [旧浏览器出现引导] → 不清 Snapshot，步骤展示已有配置，允许跳过。
- [动画误认为真实连接] → 标注演示，使用图标名片而非真实二维码，状态与真实模拟网络列表分离。
- [移动性能与可访问性] → 小画面、可暂停、减少动态效果、隐藏页不运行动画。
- [存储禁用] → 当前页面可操作，明确提示下次启动偏好无法保存。

## Migration Plan

只构建并更新独立原型 4173。旧数据键、Snapshot v4 和正式安装包不变；保留已有 README 修改。审核前不迁移正式 GUI，不归档提案。
