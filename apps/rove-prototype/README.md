## 本地预览

需要 Node 22.12+（本次 Node 22.22.2）。

```sh
cd apps/rove-prototype
npm ci
npm run dev
```

访问 `http://127.0.0.1:4173`。脚本默认只绑定回环地址。部署到局域网或远程主机须明确监听范围；不要直接把开发服务器暴露公网。

```sh
npm run build
npm run preview
```

`preview` 服务构建出的 `dist/`，同样只绑定本机 4173。生产静态托管可以直接使用 `dist/`；Hash 路由无需服务器重写。CSS、图标与脚本均本地打包，没有 CDN 依赖。

2026-09-14 用户指定局域网监听地址为 `10.1.2.237`，预览入口为 `http://10.1.2.237:4173/`。在该开发机运行 `npm run preview:lan` 可按此范围启动；仅绑定指定网卡，不监听所有网卡，不修改防火墙。默认 `dev` / `preview` 仍保留回环地址供本机测试。

### 0.5 按 Rig 筛选（已验收基线）

- 欢迎页/新会话新增第五项“管理 Rove”；设置页顶部增加对话管理说明与按钮。两处另开目标为此设备的会话，只准备检查空间和运行情况的草稿，不覆盖原草稿、不自动发送。无模型则引导添加，手动设置保留。当前不会真实扫描、清理或迁移，设置页同时说明正式接入后的影响确认原则。5 项针对性浏览器测试及类型/生产构建通过；新增入口复用既有会话/草稿 API，无新增管理端点。

- 音乐、影院、代码代理统一为第三方开源软件部署场景：Rove 负责联通管理设备与服务访问，各设备的 rove-agent（基于 Rig）安装配置软件；具体播放、媒体管理和代码代理协作由第三方软件承担，不自建专用业务编排引擎。场景说明和草稿已同步，仍只模拟。

## 安全与模拟边界

API 密钥框只接受 `demo-key`，本地接口可留空，不保存输入密钥。账号认证仅显示明确模拟流程，不发起 OAuth。接口地址不会被请求，服务按钮打开本地演示弹窗，不访问所显示的 IP。

网络二维码、URL、JSON 只用于本原型互相导入，使用 `rove-prototype-card-v1` 标识和保留的 `.invalid` 域名；不是生产 Rove 配置，也没有实现公网配置加密上传。

扫码、相机和语音入口提供能力说明或填入示例文字；附件仅暂存名称，不读取内容或上传。不把演示标为真实成功。

浏览器本地存储键为 `rove-prototype-v1`，只存演示配置、会话与模拟时间戳。重开时重算时间线并补取状态，不存在浏览器关闭后运行的后台服务。禁用本地存储时应用仍可用，但不能保证刷新保留数据。场景重置只清理本原型数据。

## 结构与协议

```text
src/App.vue                  响应式外壳、导航、平台外观
src/pages/                   会话、资源、设置/模型页面
src/components/              模型与网络表单/名片
src/ui.ts                    页面编排与注入的模拟适配器
src/domain.ts                PrototypeApi 接口及领域显示模型
src/mock.ts                  仅浏览器模拟数据与任务时间线
api/prototype.openapi.json   OpenAPI 3.1 原型契约（未实现 HTTP 服务）
```

完整的真实 API 差异及迁移边界参见 `docs/prototype-handoff.md`。当前模拟适配器用进程内方法实现，契约中的 HTTP 路由用于定义语义，不是可访问的后台地址。
